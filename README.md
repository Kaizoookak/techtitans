About Tech Titans

Tech Titans is a collaborative portfolio project developed by a team of BSIT students. It serves as a central place to introduce our team, share our technical skills, present our projects, and provide a way for visitors to contact us.

Rather than using a ready-made portfolio template, we developed a custom WordPress theme using PHP, HTML, CSS, and JavaScript. This project also gives us an opportunity to apply what we have learned in web development, teamwork, and version control.

Setup Instructions

Clone or download this repository.

Locate the MyCustomPortfolio theme folder.

Copy the folder into your WordPress themes directory:

wp-content/themes/

Start your local WordPress development environment.

Open the WordPress Admin Dashboard.

Navigate to Appearance → Themes.

Find MyCustomPortfolio and click Activate.

Visit your local website to view the portfolio.
