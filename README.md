Tech Titans — Portfolio Website
A custom-built, responsive portfolio website developed using WordPress and PHP. Tech Titans showcases our team's background, technical skills, projects, and contact information.
About the Project
Tech Titans is a group portfolio website created to present our team's capabilities as Information Technology students. It provides visitors with an overview of our team, our projects, and the technologies we use.

The website uses a custom WordPress theme developed with PHP, HTML, CSS, and JavaScript.
Features
- Home Section — Introduction to the Tech Titans team.
- About Section — Information about the team.
- Skills Section — Highlights our technical skills.
- Projects Section — Showcases our development projects.
- Contact Section — Allows visitors to send inquiries through a contact form.
- Responsive Design — Supports desktop, tablet, and mobile screens.
- Custom WordPress Theme — Built using PHP, HTML, CSS, and JavaScript.

Setup Instructions
1. Clone or download this repository.
2. Locate the MyCustomPortfolio folder.
3. Copy the folder into your WordPress themes directory:
   wp-content/themes/
4. Start your local WordPress website.
5. Log in to the WordPress Admin Dashboard.
6. Navigate to Appearance → Themes.
7. Find MyCustomPortfolio and click Activate.
8. Open your website to view the portfolio.
